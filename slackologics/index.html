How this worked

    The operating model

    What lived where.

    The communication layer was deliberately simple. Each surface had a job.

    Spec & Decisions canvas
    Product decisions, shared API contracts and instructions for the next session.
    #tasks + threads
    Task, owner and branch. Claims, status reactions, questions and implementation updates.
    #agent-log
    Session checkpoints: what changed, branch or PR, blockers and next steps.
    #main-talk
    Human direction, scope corrections, decisions and questions across the team.
    Git + local checkouts
    The implementation itself. A Slack handoff still needed the right branch, files and runtime setup.

    Who is speaking?

    Several assistants posted through human Slack accounts. Each reconstructed message therefore shows the account name and a separate session label derived from the record. A message under a teammate’s name does not, by itself, establish who typed it or whether the teammate was awake.

    These are selected historical excerpts, not a live Slack integration. Genuine thread replies and cross-channel sequences are labeled separately. Original-message links require workspace access. No credential-channel content is included.
